# 个人作品集 · 产品边界与设计工作计划

> **状态：已确认需求基线 + 尚未选定设计方案。**
> 日期：2026-10-28（修订先前 V1.0 中“保留森林视觉”的误解）。
> 这不是获批 UI 设计稿，不授权立即全面改版。

## 已确认需求（公开最小摘要）

1. 这是长期成长的个人作品集，主要服务于**作品展示和获得合适的工作机会**，兼顾商业合作与个人品牌。
2. **剧本创作和 AI 影像作品同等重要**，都需要真实、可信地展示。
3. 希望整体气质**有创意、有个性、有艺术感**；具体视觉风格尚未选择。
4. 对外公开的内容为经确认的**简介、剧本节选、演示片段**；完整作品通过私下联系提供。
5. 真实性优先：不得以未经确认的示例作品、时长、奖项、商业案例或邮箱作为真实资料。
6. 用户不希望再进行冗长的问卷访谈；已确认的需求不要反复询问，只就关键设计决策给出少量清晰选择。

### 视觉探索反馈记录（2026-10-29）

- **[用户明确否定]** 第一批所展示的三组外部网站参考（电影叙事感、艺术编辑感、数字实验感的具体例图）**均不喜欢**。不要继续沿用这三组参考图，也不要擅自将它们拼贴混搭为新方案。
- **[未能推断]** 这一反馈是针对**展示过的参考样本**；不等于用户已永久排斥所有电影感、编辑式设计或数字实验等宽泛概念，也无法据此推断确切原因。不得补写用户没说过的审美倾向。
- **[下一步提案，尚未获批]** 暂停泛化的优秀网站案例推荐，转向围绕“剧本与 AI 影像同等重要、创意与艺术感、面向求职”的原创页面探索。先呈现明显不同的首页视觉原型，让用户直接评价实际构图、字体、空间和作品展示方式；避免再以风格标签和长问卷代替画面。
- 以上仅更新规划知识，不授权修改网站界面或发布新设计。


### 第二轮原创首页视觉草案反馈（2026-10-29）

- **[用户评价：相对偏好，而非定稿]** 对四款原创首页草案 A（温暖手绘）、B（现代文艺）、C（暗调电影）、D（简约拼贴），用户表示 **A 第一眼明显更喜欢，但并非完全认可**。原因之一是 A 尚不足以清晰体现其编剧、动漫剧、影视制作等职业属性。不得据此将 A 作为最终视觉方案。
- **[用户明确否定]** B 第一眼就不喜欢；用户无法准确解释原因，不能自行归因于“讨厌极简或留白”。D 乍看不成熟，细看也觉得不好看；不宜沿用该方案的处理方式。
- **[用户具体反馈]** C 有影视感，但深暗色调及电影图片作为大背景的构成不够优雅、美观。影视专业识别度是需要解决的设计目标，不等于要使用暗色背景或整张剧照覆盖首页。
- **[用户明确偏好]** 四款草案底部“细节元素对比”一整排的局部设计语言相对喜欢，包括导航图标、按钮、卡片、装饰与字体示意。尚未区分其中最喜欢哪一类元素，不能直接断定全部细节均需采用。
- **[用户明确排除]** 不希望网站有强烈科技感；更希望表现内容创作、剧本、动漫剧和影视作品，而非“做科技的”。
- **[仍待探索]** 如何在首屏兼顾“亲和有趣”“成熟精致”和“影视/编剧职业辨识度”，同时把手绘拟人化 SVG 图标控制在局部而非整站童趣化。用户尚未能准确表述“击中自己的感觉”；应通过同内容、不同视觉权重的少量针对性对比帮助判断。
- **[助手下一轮提案，未获批准]** 停止广撒网式 ABCD 大风格分类，尝试三版更聚焦的**明亮系、成熟型、具备影视创作识别度**的首页方案：轻手绘+专业案例、明亮影视放映目录、文字与分镜并置的创作展览。固定内容元素，比较布局、字体、作品呈现和局部趣味层次。不得将该提案记为用户确认。
- 仅记录视觉偏好与下一轮探索建议，**不授权修改网站现有页面、部署新设计或使用真实未授权作品素材**。

### 第三轮原创首页视觉草案反馈（2026-10-29）

> 本轮是**新的一组 A/B/C/D**，与前一组编号对应不同画面；保留历次偏好变化，禁止把早期 A 优先错误地套用到新一轮。

- **[用户明确反馈：本轮 A]** 第一眼已经不喜欢。加入文艺、小清新的背景图片后，用户觉得有些“low”、不对劲。此次反馈是针对这种**具体背景与表现手法**，不得扩展为排斥所有暖色、自然元素或明亮背景。
- **[用户相对认可：本轮 B]** 比前一轮 B 改善，观看舒适，但缺少用户提供的那组**卡通、涂鸦、手绘拟人图标**带来的气质。用户认可网站视觉存在整体风格、字体排版、局部图标和交互动效等不同层次，图标不等于整站卡通化。
- **[用户相对偏好：本轮 D]** 这轮四个方案中 D 最好看；这是**相对排序而不是定稿**，也不表示前一轮的 D 被重新认可。
- **[用户保留开放性：本轮 C]** 黑色调很难引发喜爱，打动用户的门槛更高，**但并非绝无可能**；不得写成“一律禁止暗色页面”。
- **[用户对整体进展评价]** 两轮对比有变化，但整体提升不大，还没有遇到真正“一眼特别喜欢”的设计。需要改变视觉探索方法，而非反复更换背景图或套相同卡片布局。
- **[下一轮助手分析与提案，未获批准]** 与其持续生成同构 ABCD 整页，改为**控制变量**的探索：先用中性的同一页面骨架，分别比较字体/排版、职业身份与作品呈现、手绘图标的使用密度和位置、背景留白/色彩。尤其验证“有影视创作辨识度而不依赖暗背景”“有趣但成熟”的结合；尽量让真实剧本与 AI 影像两条内容线平等。
- **[仍待确认]** 用户真正被打动的视觉内核尚未识别，不能宣称已定为极简、艺术编辑、手账、某配色或任何特定标签。后续继续以具体画面得到反馈。
- 本次仅归档公开层面的视觉反馈，**不授权修改线上站点**。

### 第四轮交互原型反馈（2026-10-29）

- **[用户明确澄清]** 之前“看着很怪”的主要问题是首页像一张需要持续向下滚动的长海报；**不是在否定左侧悬浮栏目导航**。用户明确表示左侧导航及其他现有设计部分都没有问题。
- **[实施范围]** 保留左侧桌面导航、手机底部导航、半透明材质、局部手绘图标、按钮与卡片反馈、栏目独立切换。避免把这次反馈误解为要求推翻整套 UI。
- **[当前原型调整，仍待用户体验确认]** 将首页重组为单屏主视觉与两个并列创作入口（剧本创作 / AI 影像），移除首页纵向堆叠的 gateway 与 featured 区块；具体栏目仍保留独立视图。桌面端优先控制在一个视窗内，手机端以紧凑构图为主。
- **[待验证]** 桌面首屏是否能在常见分辨率下完整呈现、手机首屏是否清楚易用、两条创作主线是否同等醒目。只有通过实际截图和交互体验后，才能判断这轮是否改善；不代表最终视觉定稿。
- **[工程边界]** 继续在现有独立 PR 中迭代，不合并到 main、不改变线上生产页面，直到用户评审。


### 第五轮视觉与交互反馈（2026-10-29）

- **[用户明确反馈]** 当前首页布局凌乱、观感不佳；不喜欢逐渐偏黄褐与灰绿的配色，认为不够清新，且模板化 / AI 感在增强。
- **[用户指出的技术疑问]** 页面仍可上下滚动，主内容外有一层突兀的大圆角框；怀疑固定高度造成。源码检查确认桌面首页确实使用 `clamp(520px, calc(100svh - 238px), 760px)` 固定高度并裁切溢出，且外层还叠加页头、页脚和布局间距；需改为自然内容高度与响应式布局，不以固定高度和 `overflow:hidden` 强行压缩页面。
- **[用户明确纠正]** 先前参考图中的拟人化涂鸦图标只是图标样式截图，图标本身应为可编辑 SVG，且具备交互动画，例如场记板点击时“咔嗒”动作。不能把截图当作图标素材，也不能用静态、较规整的线稿替代原有表现力。
- **[历史偏好，结合既有记录]** 图标采用黑白为主、不规则粗线、物品拟人化并带表情；这是局部交互语言，不等于全站卡通化。保留用户此前喜欢的栏目切换、按钮 hover、卡片抬升 / 轻微旋转 / 阴影、透明按钮和弹窗等细节。
- **[源码核验]** 当前原型把旧 CSS 与多轮覆盖规则不断叠加，造成同一组件的边框、背景、模糊、圆角与阴影重复；当前 `Doodle` 组件为静态 inline SVG。仓库及当前可访问的项目 / Library 文件中尚未找到独立的原始图标 SVG 源文件，只有 PNG 风格参考图可读。
- **[本轮实施，待验证]** 清理重复样式；移除主内容大外框和固定高度限制；降低背景装饰与英文占位标签密度；改用更明亮、清爽、克制的颜色系统；将影像卡片中的通用山水概念图换成简洁分镜构成；重建可交互的场记板 SVG 点击动效。
- **[工程边界]** 以上是当前 Draft PR 的针对性修正，尚非最终定稿；桌面端应在常见视口自然呈现完整首页，手机端允许内容确实超出时自然滚动，不能通过固定高度裁切来假装不滚动。生产分支 `main` 不变。
