# 个人作品集 · 产品边界与设计工作计划

> **状态：已确认需求基线 + 尚未选定设计方案。**
> 日期：2026-10-28（修订先前 V1.0 中“保留森林视觉”的误解）。
> 这不是获批 UI 设计稿，不授权立即全面改版。

## 已确认需求（公开最小摘要）

1. 这是长期成长的个人作品集，主要服务于**作品展示和获得合适的工作机会**，兼顾商业合作与个人品牌。
2. **剧本创作和 AI 影像作品同等重要**，都需要真实、可信地展示。
3. 希望整体气质**有创意、有个性、有艺术感**；具体视觉风格尚未选择。
4. 对外公开的内容为经确认的**简介、剧本节选、演示片段**；完整作品通过私下联系提供。
5. 真实性优先：不得以未经确认的示例作品、时长、奖项、商业案例或邮箱作为真实资料。
6. 用户不希望再进行冗长的问卷访谈；已确认的需求不要反复询问，只就关键设计决策给出少量清晰选择。

## 现状只作为参考，不是设计授权

- 当前 `src/App.tsx` 为旧版单页原型；其中若干剧本和影像卡片为硬编码示例，需核实。
- 当前 `src/styles/globals.css` 及 `public/forest-studio.png` 是旧设计素材，新设计不必沿用。
- `visual-snapshots` 保存旧原型截图，为视觉对比与回归检查提供依据，不意味着当前视觉获批。

## 下一步设计流程（建议，尚未执行）

### 0. 知识初始化与校正

- 将详细访谈总结保存在**个人私有 Library / ChatGPT 项目文件**，不上传公开 GitHub。
- 公开仓库仅保留产品边界、工程规范、设计决策。
- 清理历史文档对森林、绿色、玻璃拟态等的强制约束。

### 1. 视觉方向探索

- 准备 3 个明显不同的艺术方向，每个都有参考画面、配色、字体和布局情绪。
- 请用户选择或组合，不使用冗长能力问卷。
- **在用户确认方向前不改生产页面。**

### 2. 产品信息架构与原型

- 基于作品类型、访问者需求、信息阅读顺序设计页面架构，现有五栏**不默认为必须保留**。
- 验证剧本与 AI 视频是否具有同等发现机会、公开节选是否合适、如何联系获取完整作品。
- 提供手机和桌面原型与交互说明，逐轮确认。

### 3. 开发实施

- 大范围 UI 重构走分支和 Pull Request。
- 不改变保留的技术基础和部署链路；必要的架构调整先讨论。
- 用真实素材逐步替换占位内容；每次提交记录修改、lint/build、部署和截图验证。

## 内容与权限清单（需要时再确认）

- 能公开的作品名称、简介、授权节选、封面与视频演示。
- 一个允许公开的联系渠道；尚未提供前不编造。
- 未核实的完整作品文件和私人访谈不放入构建资源，不做所谓“前端隐藏的私有内容”。

## 长期决策记录原则

- **用户已确认**：方可进入正式需求。
- **助手建议**：必须标记提案，不能自动解释为用户批准。
- **已否定**：记录原因，不重复推荐为默认方案。
- **待核实**：有真实证据后再更新。对每次重要讨论做一次知识归档。

详细个人访谈存于个人私有档案 `雪雪个人网站_私有访谈档案_v1.md`，不在公开仓库中。
