# 互动体验回顾与第二次迭代

## 反馈（用户明确）

- PR 预览版只有向下滚动的感觉，交互显著低于原站；信息布局和质感也低于原站，整体像低质量海报。
- 旧版虽风格不喜欢，但栏目切换、按钮 hover、透明材质、细节与动效确有价值。
- 新版的明亮方向部分可取，不能靠简单拼接新旧元素就当作设计完成；用户期待更成熟的互动体验。

## 已核验源码差异

- 主分支原版使用 `active` 状态切换五个栏目，并配有剧本弹窗、卡片浮起与旋转、焦点反馈、模糊及透明层次。
- 第一版 PR 改为多段锚点长滚动，交互反馈较单一；布局偏向静态海报。

## 本次改进（仍是视觉过渡版）

- 恢复独立栏目切换，保留首页双内容入口；支持浏览器历史、栏目深链接和移动端菜单。
- 对导航、卡片、按钮重新设计状态反馈、半透明材质与分层阴影，同时保留 C 方向浅色基调。
- Playwright 截图从滚动单页改成逐个导航点击再截图，便于真实检查。
- 原版森林背景、旧绿色、示例剧本、虚构视频与联系方式均不恢复；尚未有用户认可的真实素材。
- **本次仅更新 PR 分支，不合并 main**。下一步仍需做真正的作品详情与内容体验，而不是只提高 hover 数量。

## 第三轮：导航位置与透明质感（2026-10-29）

- **[用户明确要求]** 顶部的横向导航栏应改回左边，参考原始站点的侧栏导航。
- **[用户评价]** 现有浅色页面仍有报纸式平面感，需要更多真正的透明、通透层次；并非要求退回森林配色或背景。
- **[本轮实施]** 桌面左侧悬浮导航、手机底部五栏目 dock；背景使用柔和低饱和色光，主内容区与导航应用选择性的半透明、模糊、细边框和层次化阴影。
- **[待评审]** 当前仅是新视觉的交互/质感试验，仍需要实地检查用户的审美接受度和正式作品布局。

## 第五轮：布局、色彩与原始 SVG 交互（2026-10-29）

### 用户反馈
- 首页布局仍显凌乱；大圆角外框突兀，桌面页面出现意料之外的上下滚动。
- 配色越来越偏黄褐 / 灰绿，不够清新；渐变、玻璃模糊、重复圆角卡片与大量英文微标签强化模板化 / AI 感。
- 之前约定的组件细节与原先的拟人化手绘图标交互没有被完整保留。
- 原图标不是截图素材，而是可动画的 SVG；场记板点击时应有短促的“咔嗒”动作。

### 源码核验
- 首页外框 `.surface-stage` 使用视口计算出的固定高度并设 `overflow:hidden`；该计算未准确扣除顶部、底部和布局间距，确实可能制造页面滚动或裁切。
- 全局 CSS 存在多轮样式追加，造成样式层叠和重复的玻璃边框、阴影与圆角。
- 当前 `Doodle` 是静态 inline SVG。GitHub 当前分支 / main 仅有 `public/favicon.svg` 这一独立 SVG 资源；原始图标 SVG 文件未在当前可访问资料中找到。现有 PNG 只能作为风格参考，不能冒充原件。

### 本轮修正
- 将全局样式整理为一套清晰规则，移除主内容的固定高度与突兀外框；不裁切内容。
- 采用更干净的浅色底、清晰墨色和单一珊瑚色点缀，减少渐变、重玻璃效果与装饰标签。
- 影像入口改为分镜 / 胶片构成示意，不再以通用山水概念插画填满首屏。
- 将手绘 SVG 作为独立矢量组件，并给场记板增加点击 snap 动效；这属于根据现有 PNG 参考重建的 SVG，不宣称为原始文件。
- 自动化验收强化为：桌面首页不应因外框高度计算产生垂直滚动；不允许横向溢出；内容外框不应重新出现；场记板点击必须触发 SVG 动画。

### 状态
- `npm run lint`、`npm run build`、Playwright 桌面 / 手机截图、栏目切换与场记板 SVG 点击动画检查均通过。
- 桌面 1440×900：`document.documentElement.scrollHeight === 900`；手机 390×844：`scrollHeight === 844`；两端均无横向溢出。主内容外框边框 / 圆角为 0，溢出模式为 visible。
- Cloudflare 独立预览部署成功。仍是 Draft 视觉原型，等待用户评审；`main` 未修改，生产网站未部署这轮 UI。


## 第六轮：手记图标书写动画（2026-10-30）

- **[用户明确要求]** 以本轮提供的“叠放纸页、拟人表情、斜握书写笔”图作为手记入口图标参考，重建可编辑 SVG；PNG 仅作造型参考，不作为最终图标素材。
- **[动画交互]** 点击封面「手记」入口后，笔尖先移动至纸面首行，再依次沿三条书写线滑动，线条随笔尖逐段显现；完整动画结束后再进入手记栏目，避免切页中断。返回封面后可再次点击重播。
- **[造型约束]** 保留纸页叠层、简洁拟人表情、粗黑不规则描边、红色笔帽和少量红色强调笔触；手绘图标继续作为局部交互语言，不将整站卡通化。
- **[工程范围]** 仅更新现有 Draft PR #1 的设计分支及预览，不修改 main，不部署生产网站。
